# Comunidade Conectada

Crie um site institucional em português para uma empresa de community management e tráfego pago. Deve comunicar serviços, benefícios e forma de trabalho, com aparência profissional e moderna. Inclua seção hero, serviços, diferenciais, processo, prova social/CTA, formulário de contato funcional e botões destacados com link para WhatsApp. Use conteúdo exemplo editável e uma estrutura pronta para captar leads.
